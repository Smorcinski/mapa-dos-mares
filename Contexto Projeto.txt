# 📌 CONTEXTO COMPLETO DO PROJETO – MAPA INTERATIVO RPG (SEA OF THIEVES BASE)

## 🎯 Objetivo do projeto

O usuário está adaptando um **mapa interativo open-source do jogo Sea of Thieves**, disponível no GitHub, para uso em um **RPG próprio de piratas**, chamado **Pacto das Marés**.

O objetivo é:

* Manter o mapa base (ilhas, grade, distância, zoom, marcações)
* Customizar:

  * Rotas
  * Sistema de tempo de viagem
  * Inserção de navios e inimigos
  * Cálculo de distância em **quadrantes → km → horas → dias + horas**
  * Interface
  * Elementos visuais
* Hospedar tudo no **GitHub Pages**

---

Failed to register a ServiceWorker

---

# 🔍 Diagnóstico técnico real

## Importante:

No arquivo **src/js/sotm.js NÃO EXISTE nenhum `addEventListener`.**

Esse erro surge porque:

👉 O **webpack + babel** geram código interno com `addEventListener` nos módulos.

O erro está vindo de **um dos módulos importados**, principalmente:

```js
import * as pwa from './modules/pwa.js';
```

---

# ⚠️ Origem real do bug

O projeto original foi feito para rodar com:

* CDN próprio
* Service Worker ativo
* Estrutura PWA completa

No **GitHub Pages**, não existe:

```
/service-worker.js
```

Resultado:

* O módulo `pwa.js` tenta registrar um service worker inexistente
* Ele também tenta acessar elementos DOM que não existem
* Isso gera **null.addEventListener**, quebrando TODO o carregamento

---

# 🧠 Conclusão técnica

👉 **O mapa está quebrando por causa do sistema PWA, não por causa do mapa em si.**

---

# ✅ Solução correta proposta

Desativar totalmente o PWA:

### 1) No `sotm.js`, remover:

```js
import * as pwa from './modules/pwa.js';
```

### 2) Remover qualquer chamada:

```js
pwa.*
```

### 3) Garantir que não exista tentativa de registrar:

```
navigator.serviceWorker.register(...)
```
